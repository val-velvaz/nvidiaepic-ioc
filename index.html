NVIDIAEpic.py / RazerControlCenter: what it is and how to remove it

Last updated: November 2, 2026 · Based on a real case analyzed by hand · Versión en español

Did you land here searching for NVIDIAEpic, RazerControlCenter or one of the hashes?
Your computer is probably infected. From another device (your phone or another computer), change your passwords and sign out of all your open sessions. Then follow the cleanup guide. Do not change passwords from the infected computer.

Summary

This is a multi-stage attack. It starts with a fake captcha (a technique known as ClickFix) that asks you to press Win+R, paste and hit Enter. Doing that unknowingly runs a PowerShell script that:

  1. Disables Windows protections (AMSI) and downloads encrypted code that runs only in memory. Most likely an infostealer that steals browser passwords, cookies and sessions.
  2. Installs a Python crypto clipper (NVIDIAEpic.py) that starts with Windows and swaps any wallet address you copy for one of the attacker's.
  3. Installs a malicious Edge extension posing as "Save to Google Drive" by "Google inc.", with access to cookies, clipboard, history and every page you visit.

Common signs: your Discord or other social accounts post scams on their own (for example, a fake "MrBeast crypto casino" with a promo code), unknown sessions show up, or you get sign-in alerts you didn't trigger.

At the time of writing, no antivirus detected these files (VirusTotal didn't know the hashes and Microsoft Defender found nothing). The code is heavily obfuscated and is probably generated differently for each victim, so your hashes may not match. Rely on the paths and names more than on the hashes.

How it gets in

In the analyzed case, the infection started with a link in the description of an old YouTube video (a piano cover promising free sheet music). The original domain was probably abandoned and now redirects through ad networks:

  • youtubesheetmusic[.]com/artists/…: original link in the video description
  • click-v4.junclikrmedi[.]com/click?i=…: ad click tracker
  • breakthroughdev[.]buzz/index51.php?flow_id=…&campaign=…: traffic reselling network
  • hya.codedevfuture[.]buzz/?…: fake captcha asking for Win+R → Ctrl+V → Enter, then shows "site not found"
  • %TEMP%\S422.ps1 is created; it downloads hxxp://45.155.69[.]180/yrjrs/sava.ra and runs it in memory
Rule of thumb: no legitimate website will ever ask you to paste something into Win+R, PowerShell or a terminal to "verify you are human". If you see that, close the page.

Am I infected? Quick check

This script only reads; it doesn't change or delete anything. Open a normal PowerShell window (no administrator needed) and read it before running it. That's good practice with any command you find online, including this one.

$found = $false
# 1. Clipper folder
if (Test-Path "$env:ProgramData\RazerControlCenter") {
  Write-Host "[!] Found $env:ProgramData\RazerControlCenter" -ForegroundColor Red; $found = $true
  Get-ChildItem "$env:ProgramData\RazerControlCenter" -Filter *.py | Get-FileHash -Algorithm SHA256 | Format-List
}
# 2. Startup entry
$run = Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run'
$run.PSObject.Properties | Where-Object { $_.Name -notlike 'PS*' -and ($_.Name -eq 'NVIDIAEpic' -or "$($_.Value)" -match 'RazerControlCenter|pythonw') } | ForEach-Object {
  Write-Host "[!] Suspicious startup entry: $($_.Name) = $($_.Value)" -ForegroundColor Red; $found = $true
}
# 3. Fake "Save to Google Drive" extension in a LOCALAPPDATA folder
Get-ChildItem $env:LOCALAPPDATA -Directory -ErrorAction SilentlyContinue | ForEach-Object {
  $m = Join-Path $_.FullName 'manifest.json'
  if ((Test-Path $m) -and (Select-String -Path $m -Pattern 'Save to Google Drive' -Quiet)) {
    Write-Host "[!] Fake extension in: $($_.FullName)" -ForegroundColor Red; $found = $true
  }
}
# 4. PowerShell loader
Get-ChildItem $env:TEMP -Filter 'S*.ps1' -ErrorAction SilentlyContinue | Where-Object { (Get-Content $_.FullName -Raw) -match 'VirtualAlloc' } | ForEach-Object {
  Write-Host "[!] Suspicious script: $($_.FullName)" -ForegroundColor Red; $found = $true
}
if (-not $found) { Write-Host "None of the known indicators were found." -ForegroundColor Green }

Finding nothing doesn't guarantee you're clean: the random names can change between victims.

Cleanup

The safest option is to reinstall Windows, because part of the attack runs in memory and there's no way to know everything it did. If you'd rather clean it by hand, ideally do it from another operating system (a Linux live USB or dual boot) with Windows shut down, so the malware isn't running. If you do it from Windows, first disconnect from the internet and don't open Edge.

1. Before touching the computer

From your phone or another clean device, change your passwords and sign out of all sessions. Details in Accounts and passwords.

2. Remove the startup entry

Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'NVIDIAEpic' -ErrorAction SilentlyContinue
Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\StartupApproved\Run' -Name 'NVIDIAEpic' -ErrorAction SilentlyContinue

Restart the computer so pythonw.exe stops running.

3. Unregister the Edge extension

With Edge fully closed, rename the Secure Preferences file in every profile where the extension is registered. On the first line, put the folder name the check script found (just the name, e.g. BaZqZuJmdaVeNu). Do this before deleting the folder in step 4.

$ext = 'FOLDER_NAME'   # replace with the real name
Get-Process msedge -ErrorAction SilentlyContinue | Stop-Process -Force
$ud = "$env:LOCALAPPDATA\Microsoft\Edge\User Data"
Get-ChildItem $ud -Recurse -Filter 'Secure Preferences' -ErrorAction SilentlyContinue |
  Where-Object { Select-String -Path $_.FullName -Pattern $ext -SimpleMatch -Quiet } |
  ForEach-Object { Rename-Item $_.FullName ($_.Name + '.infected.bak'); Write-Host "Renamed: $($_.FullName)" }

Edge creates a new one when it opens. You may need to re-enable some legitimate extensions; your bookmarks, history and saved passwords are not in that file. Then open edge://extensions in every profile and make sure "Save to Google Drive" is gone. If you use Chrome or another Chromium-based browser, check its User Data folder too.

4. Delete the files

  • C:\ProgramData\RazerControlCenter\ (entire folder)
  • %TEMP%\S422.ps1 (or a similar .ps1 created at the same time)
  • The extension folder in %LOCALAPPDATA% (the one the check script found)
  • The .e4 file and the 64-byte .png files in %LOCALAPPDATA% created at the same time
  • %LOCALAPPDATA%\CrashDumps\powershell.exe.*.dmp from that date

To see what else was created at that moment, look for files in %LOCALAPPDATA%, %APPDATA%, %ProgramData% and %TEMP% with the same date and time as NVIDIAEpic.py.

5. Verify

  • Run the check script again.
  • Also check HKLM\Software\Microsoft\Windows\CurrentVersion\Run, the Startup folders, scheduled tasks and Defender exclusions. Sysinternals Autoruns shows almost all of this on one screen.
  • Run a Microsoft Defender Offline scan (Windows Security → Virus & threat protection → Scan options).
  • Turn on Potentially unwanted app blocking in Windows Security → App & browser control → Reputation-based protection.

Accounts and passwords

Do this from a clean device. Assume everything saved in the browser was stolen.

  • Change the passwords of everything you had saved or open in the browser. Use long passwords (16+ characters), a different one for each site, ideally with a password manager.
  • Sign out of all sessions on every service. Stolen cookies let attackers in without a password or 2FA, so changing the password isn't always enough.
  • Turn on 2FA with an authenticator app or a passkey, not SMS.
  • Email: check recent activity, devices, and filter and forwarding rules. Attackers sometimes create rules to hide security alerts.
  • Discord: change your password (it invalidates tokens), check "Devices" and "Authorized Apps", and delete any messages sent from your account.
  • GitHub / development: look for commits you didn't make, and rotate SSH keys, access tokens, and any .ovpn files or credentials stored on the disk, including inside WSL.
  • Crypto: if you had wallets on that computer, move the funds to a new wallet created on a clean device. Check recent transactions against the wallet list.
  • Cards: if you had cards saved in the browser, check your statements and consider requesting a new card.
  • Warn your contacts not to open links sent from your accounts.

Where to report

  • URLhaus: distribution URLs and domains.
  • MalwareBazaar: samples and hashes.
  • Google Safe Browsing: so Chrome and Edge block the domains.
  • YouTube: Report → Spam or misleading on the video with the link.
  • The platform where the scam reached you (Discord, etc.) and, if you lost money, your country's cybercrime police.
